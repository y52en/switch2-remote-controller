# Documentation media

Place optimized public documentation media here.

- Photos and screenshots: WebP or PNG, normally at most 1600 px wide.
- Video: host externally and commit only a poster image plus its link.
- Raw recordings belong in `docs/assets/raw/`, which is ignored by Git.
- Remove serial numbers, account names, room codes, and device paths before use.

Suggested future files:

- `hardware-overview.webp`
- `controller-ui.webp`
- `pairing-poster.webp`
